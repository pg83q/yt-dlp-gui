# yt-dlp GUI

## 🇯🇵 Japanese

**yt-dlpをシンプルに、かつスタイリッシュなデザインでGUI化したアプリです。**

### 使い方
1. 上の入力欄に **URL** を入力します。
2. 真ん中の入力欄に **ダウンロード先** を指定します。
3. **ファイル形式** を選択します。
4. 一番下のボタンを押してダウンロード開始！

---

## 🇺🇸 English

**A simple and well-designed GUI frontend for yt-dlp.**

### How to use
1. Enter the **URL** in the top field.
2. Specify the **download destination** in the middle field.
3. Select the **file format**.
4. Press the button at the bottom to start downloading!

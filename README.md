# yt-dlp gui
## Japanese
yt-dlpをシンプルに,かつデザイン良くGUIにしたものです.
使い方は:
1.上の欄にURLを入れる
2.真ん中の欄にダウンロード先を入れる
3.ファイル形式を選ぶ
4.一番下のボタンを押す

## English
It is a simple and well-designed GUI version of yt-dlp.
How to use:
1.Enter URL in the field above
2. Enter download destination in the middle field
3.Select the file format**
4. Press the bottom button**
